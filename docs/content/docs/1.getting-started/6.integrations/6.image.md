## Installation

To get started, you can follow the official [guide](https://image.nuxt.com/get-started/installation) or in summary:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/image
```

```bash [yarn]
yarn add @nuxt/image
```

```bash [npm]
npm install @nuxt/image
```

```bash [bun]
bun add @nuxt/image
```

::

Then, add the `@nuxt/image` module in your `nuxt.config.ts`:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: [
    '@nuxt/ui',
    '@nuxt/image'
  ],
  css: ['~/assets/css/main.css']
})
```

## Usage

When `@nuxt/image` is installed, Nuxt UI renders the [`<NuxtImg>`](https://image.nuxt.com/usage/nuxt-img) component instead of the native `img` tag in the following components:

- [Avatar](/docs/components/avatar)
- [BlogPost](/docs/components/blog-post)
- [ChangelogVersion](/docs/components/changelog-version)
- [ColorModeImage](/docs/components/color-mode-image)
- [ProseImg](/docs/typography/images-and-embeds)

There is nothing else to configure. Any `<NuxtImg>` prop you pass to these components, like `format`, `quality` or `provider`, is forwarded to it:

```vue
<template>
  <UAvatar src="https://github.com/benjamincanac.png" format="webp" />

  <UBlogPost
    title="Introducing Nuxt Image"
    :image="{ src: '/blog/nuxt-image.png', format: 'webp', quality: 80 }"
  />
</template>
```

::tip
The Avatar passes its size as `width` and `height`, so `<NuxtImg>` requests an image that matches the rendered size.
::

### Opt-out

To render a native `img` tag on a single Avatar, use the `as` prop:

```vue
<template>
  <UAvatar src="https://github.com/benjamincanac.png" :as="{ img: 'img' }" />
</template>
```
