Nuxt UI v5 is currently in alpha. Follow the progress in the [v5 tracking issue](https://github.com/nuxt/ui/issues/6918) and share feedback on the [v5 roadmap](https://github.com/nuxt/ui/discussions/6610).

This guide lists the breaking changes from v4 and is updated as the alpha progresses.

## Migrate your project

Update to the latest v5 alpha:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui@next
```

```bash [yarn]
yarn add @nuxt/ui@next
```

```bash [npm]
npm install @nuxt/ui@next
```

```bash [bun]
bun add @nuxt/ui@next
```

::

## Changes from v4

### Optional peer dependencies

The dependencies of the [`Editor`](/docs/components/editor), [`Carousel`](/docs/components/carousel) and [`Table`](/docs/components/table) components are no longer installed with Nuxt UI. They are optional peer dependencies, so projects that don't use these components no longer download them.

If you use the `Editor` component, install TipTap:

::code-group{sync="pm"}


### Variants engine

Nuxt UI no longer depends on [Tailwind Variants](https://www.tailwind-variants.org/). Components are now styled by an engine that ships with the library, with the same API and the same semantics: `base`, `slots`, `variants`, `compoundVariants` and `defaultVariants` resolve to exactly the same classes as before.

Your themes, your `app.config.ui` and your `:ui` overrides keep working untouched. Two things can affect you.

If you import `tailwind-variants` in your own code, it is no longer installed for you:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add tailwind-variants
```

```bash [yarn]
yarn add tailwind-variants
```

```bash [npm]
npm install tailwind-variants
```

```bash [bun]
bun add tailwind-variants
```

::

If you import its types, they now come from `@nuxt/ui`:

```diff
-import type { ClassValue, TVVariants } from 'tailwind-variants'
+import type { ClassValue, TVVariants } from '@nuxt/ui'
```

The one rename is the config type, since `TVConfig` already means something else in Nuxt UI (the shape of `app.config.ui`):

```diff
-import type { TVConfig } from 'tailwind-variants'
+import type { TVMergeConfig } from '@nuxt/ui'
```

::note
The type rename can't be applied by a find and replace: `TVConfig` is a valid Nuxt UI type too, so only imports coming from `tailwind-variants` should change.
::
