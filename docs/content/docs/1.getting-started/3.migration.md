Nuxt UI v5 is currently in alpha. Follow the progress in the [v5 tracking issue](https://github.com/nuxt/ui/issues/6918) and share feedback on the [v5 roadmap](https://github.com/nuxt/ui/discussions/6610).

This guide lists the breaking changes from v4 and is updated as the alpha progresses.

## Migrate your project

Update to the latest v5 alpha:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @nuxt/ui@next
```

```bash [yarn]
yarn add @nuxt/ui@next
```

```bash [npm]
npm install @nuxt/ui@next
```

```bash [bun]
bun add @nuxt/ui@next
```

::

## Changes from v4

### Drawer built on Reka UI

The [`Drawer`](/docs/components/drawer) component is now built on Reka UI's `Drawer` primitive and `vaul-vue` is no longer a dependency.

Nesting is detected automatically, so the `nested` prop is gone:

```diff
-<UDrawer nested>
+<UDrawer>
```

`activeSnapPoint` is renamed to `snapPoint`, with `defaultSnapPoint` for the uncontrolled case:

```diff
-<UDrawer v-model:active-snap-point="snapPoint" :snap-points="[0.4, 0.8, 1]">
+<UDrawer v-model:snap-point="snapPoint" :snap-points="[0.4, 0.8, 1]">
```

The props that only existed for `vaul-vue`'s background scaling and body handling have no equivalent in Reka UI and are removed: `shouldScaleBackground`, `setBackgroundColorOnScale`, `closeThreshold`, `scrollLockTimeout`, `fixed`, `noBodyStyles`, `handleOnly` and `preventScrollRestoration`.

```diff
-<UDrawer should-scale-background handle-only>
+<UDrawer>
```

Two parts of this can't be handled by a find-and-replace:

- Removing `shouldScaleBackground` also removes the effect it enabled. The page behind the drawer no longer scales down, and the `data-vaul-drawer-wrapper` attribute it required can be deleted from your app root.
- The `data-vaul-*` attributes are gone from the DOM. Any CSS or test selector written against them needs to move to `[data-slot]` or to the Reka UI attributes (`data-state`, `data-swipe-direction`, `data-swiping`).

### Optional peer dependencies

The dependencies of the [`Editor`](/docs/components/editor), [`Carousel`](/docs/components/carousel) and [`Table`](/docs/components/table) components are no longer installed with Nuxt UI. They are optional peer dependencies, so projects that don't use these components no longer download them.

If you use the `Editor` component, install TipTap:

::code-group{sync="pm"}

```bash [pnpm]
pnpm add @tiptap/core @tiptap/extension-bubble-menu @tiptap/extension-code @tiptap/extension-drag-handle @tiptap/extension-drag-handle-vue-3 @tiptap/extension-floating-menu @tiptap/extension-horizontal-rule @tiptap/extension-image @tiptap/extension-mention @tiptap/extension-placeholder @tiptap/markdown @tiptap/pm @tiptap/starter-kit @tiptap/suggestion @tiptap/vue-3
```

```bash [yarn]
yarn add @tiptap/core @tiptap/extension-bubble-menu @tiptap/extension-code @tiptap/extension-drag-handle @tiptap/extension-drag-handle-vue-3 @tiptap/extension-floating-menu @tiptap/extension-horizontal-rule @tiptap/extension-image @tiptap/extension-mention @tiptap/extension-placeholder @tiptap/markdown @tiptap/pm @tiptap/starter-kit @tiptap/suggestion @tiptap/vue-3
```

```bash [npm]
npm install @tiptap/core @tiptap/extension-bubble-menu @tiptap/extension-code @tiptap/extension-drag-handle @tiptap/extension-drag-handle-vue-3 @tiptap/extension-floating-menu @tiptap/extension-horizontal-rule @tiptap/extension-image @tiptap/extension-mention @tiptap/extension-placeholder @tiptap/markdown @tiptap/pm @tiptap/starter-kit @tiptap/suggestion @tiptap/vue-3
```


When one of these components is used without its dependencies installed, the build fails with an error listing the packages to install.
