## Theme structure

Each Nuxt UI component is styled by a theme, a file in [`src/runtime/theme`](https://github.com/nuxt/ui/tree/v5/src/runtime/theme) that holds its classes. A theme has four keys: `slots`, `variants`, `defaultVariants` and `compoundVariants`.

### Slots

Components can have multiple `slots`, each representing an element of the component.

Let's take the [Card](/docs/components/card) component as an example, which has one slot per section:

::code-group

```ts [src/runtime/theme/card.ts]
export default {
  slots: {
    root: 'rounded-lg overflow-hidden',
    header: 'p-4 sm:px-6',
    title: 'text-strong font-semibold',
    description: 'mt-1 text-muted text-sm',
    body: 'p-4 sm:p-6',
    footer: 'p-4 sm:px-6'
  }
}
```

```vue [src/runtime/components/Card.vue]
<template>
  <Primitive :as="props.as" data-slot="card" :class="ui.root({ class: [props.ui?.root, props.class] })">
    <div data-slot="card-header" :class="ui.header({ class: props.ui?.header })">
      <slot name="header" />
    </div>

    <div data-slot="card-body" :class="ui.body({ class: props.ui?.body })">
      <slot />
    </div>

    <div data-slot="card-footer" :class="ui.footer({ class: props.ui?.footer })">
      <slot name="footer" />
    </div>
  </Primitive>
</template>
```

::

::note
The snippets above are abridged. The real component also renders each section only when it has content, and the theme adds a `variant` on top of the slots.
::

Components made of a single element have one `root` slot, like the [Container](/docs/components/container) component:

```ts [src/runtime/theme/container.ts]
export default {
  slots: {
    root: 'w-full max-w-(--ui-container-width) mx-auto px-(--ui-gutter)'
  }
}
```

### Variants

Components support `variants`, which add classes to their `slots` based on the component props.

For example, the [Avatar](/docs/components/avatar) component uses a `size` variant to control its size:

```ts [src/runtime/theme/avatar.ts] {6-18}
export default {
  slots: {
    root: 'inline-flex items-center justify-center shrink-0 select-none rounded-full align-middle bg-accent-soft',
    image: 'size-full rounded-[inherit] object-cover'
  },
  variants: {
    size: {
      sm: {
        root: 'size-7 text-sm'
      },
      md: {
        root: 'size-8 text-base'
      },
      lg: {
        root: 'size-9 text-lg'
      }
    }
  },
  defaultVariants: {
    size: 'md'
  }
}
```

This way, the `size` prop applies the matching classes to the `root` slot:

::component-code{slug="avatar"}
---
ignore:
  - src
props:
  src: 'https://github.com/nuxt.png'
  size: lg
---
::

### Default variants

The `defaultVariants` key sets the value of each variant when no prop is passed. The [Avatar](/docs/components/avatar) above defaults to `size: 'md'`.

::tip{to="/docs/components/theme#default-variants"}
You can change the default `size` and `color` of every component that uses `md` and `primary` with `ui.defaultVariants` in your global config, or with the `'*'` key of the Theme component's `props`.
::

### Compound variants

Some components use `compoundVariants` to apply classes when several variant conditions match at the same time.

For example, the [Chip](/docs/components/chip) component moves its dot onto the corner of its target for each `position`, unless `inset` is set:

```ts [src/runtime/theme/chip.ts] {14-22}
export default {
  slots: {
    base: 'rounded-full ring ring-bg'
  },
  variants: {
    position: {
      'top-right': { base: 'top-0 right-0' },
      'bottom-right': { base: 'bottom-0 right-0' }
    },
    inset: {
      false: ''
    }
  },
  compoundVariants: [{
    position: 'top-right',
    inset: false,
    class: { base: '-translate-y-1/2 translate-x-1/2 transform' }
  }, {
    position: 'bottom-right',
    inset: false,
    class: { base: 'translate-1/2 transform' }
  }]
}
```

## Customize theme

You can customize Nuxt UI components for your whole app, for a part of it or for a single instance. The classes you add are merged with the theme's, so `font-bold` replaces the theme's `font-medium` instead of sitting next to it.

::tip
You can explore the theme of each component in two ways:

- Check the `Theme` section in the documentation of each component.
- Browse the source code in the GitHub repository at [`src/runtime/theme`](https://github.com/nuxt/ui/tree/v5/src/runtime/theme).
::

### Global config

::framework-only
#nuxt
Customize components across your whole app in your `app.config.ts`, with the same structure as the theme itself. Use `slots` for the [`slots`](#slots), `variants` for the [`variants`](#variants) and `defaultVariants` for their [default values](#default-variants):
#vue
Customize components across your whole app with the `ui` option of the Vue plugin in your `main.ts`, with the same structure as the theme itself. Use `slots` for the [`slots`](#slots), `variants` for the [`variants`](#variants) and `defaultVariants` for their [default values](#default-variants):
::

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [src/main.ts]
import ui from '@nuxt/ui/vue-plugin'

app.use(ui, {
  ui: {
    button: {
      slots: {
        base: 'font-bold'
      },
      variants: {
        size: {
          md: {
            leadingIcon: 'size-4'
          }
        }
      },
      defaultVariants: {
        color: 'neutral',
        variant: 'outline'
      }
    }
  }
})
```
:::
::

::note
In this example, `font-bold` overrides `font-medium` on all buttons, and the leading icon gets `size-4` when `size="md"`. The buttons now default to `color="neutral"` and `variant="outline"`.
::

::framework-only
#nuxt
:::tip
The app config reaches every page, `error.vue` included, and merges across [layers](https://nuxt.com/docs/getting-started/layers). The variant values you add there are part of the component's prop types, and it's where the [icon set](/docs/getting-started/integrations/icons/nuxt#theme) of your app goes.
:::

#vue
:::note
The variant values you add there aren't part of the component's prop types. The [icon set](/docs/getting-started/integrations/icons/vue#theme) of your app goes in the `icons` option of the Vite plugin, which bundles it.
:::
::

::tip{to="/docs/getting-started/theme/css-variables#control"}
To restyle a size, set its control variables rather than a padding, so icon-only buttons and field icons follow.
::

### Theme component

Use the [Theme](/docs/components/theme) component to customize the components of a part of your app, on top of your global config. Use `ui` for the [`slots`](#slots), `variants` for the [`variants`](#variants) and `props` for the default value of any prop. It also takes [`icons`](/docs/components/theme#icons) and [`unstyled`](/docs/components/theme#unstyled):

::component-example
---
name: 'theme-ui-example'
---
::

Its props are reactive, so it can also switch themes at runtime.

### Function slots

By default, your classes are merged with the theme's. Set a slot to a function to replace them instead. It receives the classes it replaces, so you can keep part of them, and the classes of the `variants` still apply on top. It runs once per configuration, so it should only depend on its argument:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::

#vue
:::div
```ts [src/main.ts]
app.use(ui, {
  ui: {
    button: {
      slots: {
        label: () => 'text-base font-bold'
      }
    }
  }
})
```
:::
::

::framework-only
#nuxt
:::warning
In `app.config.ts`, set a function slot in one place only. Nuxt merges the `app.config.ts` of every [layer](https://nuxt.com/docs/getting-started/layers) with `defuFn`, which calls your function and keeps its result, so Nuxt UI receives a plain string that is merged instead of replacing the classes.
:::
::

The `ui` prop of the Theme component takes function slots too: `<UTheme :ui="{ button: { label: () => 'text-base font-bold' } }">`.

::tip{to="/docs/components/theme#unstyled"}
To remove the theme's classes from many components at once, wrap them in `<UTheme unstyled>`.
::

### `ui` prop

You can also override the **slots** of a single component with the `ui` prop. It takes priority over the global config, the Theme component and the `variants`:

::component-code{slug="button"}
---
prettier: true
ignore:
  - ui.trailingIcon
  - color
  - variant
  - size
  - icon
props:
  trailingIcon: i-lucide-chevron-right
  size: md
  color: neutral
  variant: outline
  ui:
    trailingIcon: 'rotate-90 size-3'
slots:
  default: |

    Button
---
::

::note
In this example, the `trailingIcon` slot gets `size-3` even though the `md` size variant sets its own size.
::

A slot can be a function here too. It receives the resolved classes, `variants` included, and only `class` still applies on top of its result:

```vue
<template>
  <UButton :ui="{ label: () => 'text-base font-bold' }" label="Button" />
</template>
```

::warning
On the root slot, the resolved classes include the `[--ui-accent:…]` class of the `color`. Keep it in what you return, or the component loses its color.
::

### `class` prop

Use the `class` prop to override the classes of the `root` slot, `base` on a Button. It applies last:

::component-code{slug="button"}
---
props:
  class: 'font-bold rounded-full'
slots:
  default: Button
---
::

::note
In this example, the `font-bold` class overrides the default `font-medium` class on this button. [Icon](/docs/components/icon) has no `ui` prop, so use `class` to style it.
::
