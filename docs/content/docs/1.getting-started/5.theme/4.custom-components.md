## Overview

Your own components can be styled by a theme like the ones Nuxt UI ships. They then read your [global config](/docs/getting-started/theme/components#global-config), follow the [Theme](/docs/components/theme) component, its `unstyled` prop included, and get the Tailwind CSS prefix of your app, with the same `ui` and `class` props as any Nuxt UI component.

## Write a theme

A theme has the same [structure](/docs/getting-started/theme/components#theme-structure) as Nuxt UI's. Declare it with `defineTheme`, which checks its `compoundVariants` and `defaultVariants` against its `variants`:

```ts
import { defineTheme } from '@nuxt/ui/utils/theme'

const theme = defineTheme({
  slots: {
    root: 'inline-flex items-center gap-1 rounded-full px-2 py-0.5 text-xs font-medium',
    icon: 'size-3.5 shrink-0'
  },
  variants: {
    variant: {
      soft: { root: 'bg-accent-soft text-accent' },
      outline: { root: 'ring ring-inset ring-accent/50 text-accent' }
    }
  },
  defaultVariants: {
    variant: 'soft'
  }
})
```

It can sit in the component itself or in a file of its own, anywhere Tailwind CSS scans your source.

### Extend a theme

To build on a Nuxt UI component, import its theme from `#build/ui/<name>` and extend it with `extendTheme`. Your classes are added to its classes the way your global config adds them, its variants stay available and its `compoundVariants` apply before yours. The theme you import is the one of the Nuxt UI version you have installed, so your component follows its changes:

```ts
import { extendTheme } from '@nuxt/ui/utils/theme'
import card from '#build/ui/card'

const theme = extendTheme(card, {
  slots: {
    body: 'flex flex-col gap-1',
    label: 'flex items-center gap-1.5 text-sm text-muted',
    value: 'text-2xl font-semibold text-strong tabular-nums',
    delta: 'text-xs font-medium'
  },
  variants: {
    trend: {
      up: { delta: 'text-success' },
      down: { delta: 'text-error' },
      flat: { delta: 'text-muted' }
    }
  },
  defaultVariants: {
    trend: 'flat'
  }
})
```

This theme has the slots of the [Card](/docs/components/card) and its `variant` variant, plus its own slots and `trend` variant. Its `body` keeps the Card's padding and adds `flex flex-col gap-1`.

A slot set to a function replaces the classes of the theme it extends instead. It receives them, so you can keep part of them:

```ts
extendTheme(card, {
  slots: {
    body: () => 'grid grid-cols-2 gap-2 p-3'
  }
})
```

::note
Importing the theme also tells [`componentDetection`](/docs/getting-started/installation/nuxt#componentdetection) to keep the Card's classes in your CSS, even when your app doesn't render a Card.
::

## Style a component

Pass the theme to `useComponentTheme` with the name your component is customized under and its props. It returns the props, resolved from your global config and the Theme components around it, and `ui`, with one function per slot:

```vue [app/components/AcmeStat.vue]
<script lang="ts">
import type { ComponentThemeConfig } from '@nuxt/ui'
import { extendTheme } from '@nuxt/ui/utils/theme'
import card from '#build/ui/card'

const theme = extendTheme(card, {
  // The theme above
})

type AcmeStat = ComponentThemeConfig<typeof theme, 'acmeStat'>

export interface AcmeStatProps {
  label: string
  value: string | number
  delta?: number
  trend?: AcmeStat['variants']['trend']
  variant?: AcmeStat['variants']['variant']
  class?: any
  ui?: AcmeStat['slots']
}
</script>

<script setup lang="ts">
const _props = defineProps<AcmeStatProps>()

const { props, ui } = useComponentTheme('acmeStat', _props, theme, props => ({
  trend: props.trend ?? (!props.delta ? 'flat' : props.delta > 0 ? 'up' : 'down')
}))
</script>

<template>
  <div :class="ui.root()">
    <div :class="ui.body()">
      <div :class="ui.label()">{{ props.label }}</div>
      <div :class="ui.value()">{{ props.value }}</div>
      <div v-if="props.delta !== undefined" :class="ui.delta()">{{ props.delta }}%</div>
    </div>
  </div>
</template>
```

The variants of the theme are read from the props of the same name, here `variant` and `trend`. The last argument gives the value of the ones your component works out itself, and receives the resolved props. Here `trend` follows the sign of `delta` when it isn't set.

Each slot function already applies the `ui` prop of its slot, and the one of the `root` slot the `class` prop, so `<AcmeStat class="col-span-2" :ui="{ value: 'text-primary' }" />` works like on any Nuxt UI component. The classes you pass a slot function come before them: `ui.value({ class: 'truncate' })`.

::tip
`ComponentThemeConfig` types the variants and slots from your theme and your global config, so a `variant` value you add in your `app.config.ts` is a valid prop.
::

## Customize it

Your component is customized the way Nuxt UI's are, under the name you gave `useComponentTheme`. For those keys to be typed, register the theme in `CustomThemes` and the props in `ThemeDefaults`, next to the component:

```ts [app/components/AcmeStat.vue]
declare module '@nuxt/ui' {
  interface CustomThemes {
    acmeStat: typeof theme
  }
  interface ThemeDefaults {
    acmeStat?: Partial<AcmeStatProps>
  }
}
```

`CustomThemes` types your global config and the `ui` and `variants` of the Theme component, `ThemeDefaults` its `props`. Then in your `app.config.ts`:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    acmeStat: {
      slots: {
        value: 'text-3xl'
      },
      defaultVariants: {
        variant: 'soft'
      }
    }
  }
})
```

And with the Theme component, for a part of your app:

```vue
<template>
  <UTheme :props="{ acmeStat: { variant: 'subtle' } }" :ui="{ acmeStat: { root: 'rounded-none' } }">
    <AcmeStat label="Revenue" value="$48,210" :delta="12.4" />
  </UTheme>
</template>
```

::note
With a [`tailwindPrefix`](/docs/getting-started/installation/nuxt#tailwindprefix), write the classes of your own themes with the prefix, `tw:text-2xl`, for Tailwind CSS to find them. Nuxt UI adds the prefix to the classes that don't have it, like the ones of the theme you extend.
::
