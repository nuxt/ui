## Colors

Nuxt UI provides Tailwind CSS utility classes for each [color alias](/docs/getting-started/theme/design-system#color-system), so you can use class names like `text-error` or `bg-success`:

::code-preview
[Primary]{class="text-primary text-sm px-4 py-1.5 inline-block"}
[Secondary]{class="text-secondary text-sm px-4 py-1.5 inline-block"}
[Success]{class="text-success text-sm px-4 py-1.5 inline-block"}
[Info]{class="text-info text-sm px-4 py-1.5 inline-block"}
[Warning]{class="text-warning text-sm px-4 py-1.5 inline-block"}
[Error]{class="text-error text-sm px-4 py-1.5 inline-block"}
[Neutral]{class="text-neutral text-sm px-4 py-1.5 inline-block"}

#code
```vue
<template>
  <span class="text-primary">Primary</span>
  <span class="text-secondary">Secondary</span>
  <span class="text-success">Success</span>
  <span class="text-info">Info</span>
  <span class="text-warning">Warning</span>
  <span class="text-error">Error</span>
  <span class="text-neutral">Neutral</span>
</template>
```
::

Each alias is a CSS variable that picks a shade of its palette for light and dark modes:

::code-group
```css [Light]
:root {
  --ui-primary: var(--ui-color-primary-500);
  --ui-secondary: var(--ui-color-secondary-500);
  --ui-success: var(--ui-color-success-500);
  --ui-info: var(--ui-color-info-500);
  --ui-warning: var(--ui-color-warning-500);
  --ui-error: var(--ui-color-error-500);
  --ui-neutral: var(--ui-color-neutral-900);
}
```

```css [Dark]
.dark {
  --ui-primary: var(--ui-color-primary-400);
  --ui-secondary: var(--ui-color-secondary-400);
  --ui-success: var(--ui-color-success-400);
  --ui-info: var(--ui-color-info-400);
  --ui-warning: var(--ui-color-warning-400);
  --ui-error: var(--ui-color-error-400);
  --ui-neutral: var(--ui-color-neutral-50);
}
```
::

::tip{to="/docs/getting-started/theme/design-system#configure-colors"}
To pick other shades, give them to the `@nuxt/ui/colors` plugin, like `primary: sky 700 300`.
::

## Text

Nuxt UI provides Tailwind CSS utility classes for text colors, so you can use class names like `text-muted` or `text-strong`:

::code-preview
[Faint]{class="text-faint text-sm px-4 py-1.5 inline-block rounded-md"}
[Muted]{class="text-muted text-sm px-4 py-1.5 inline-block rounded-md"}
[Default]{class="text-default text-sm px-4 py-1.5 inline-block rounded-md"}
[Strong]{class="text-strong text-sm px-4 py-1.5 inline-block rounded-md"}
[Contrast]{class="text-contrast bg-neutral text-sm px-4 py-1.5 inline-block rounded-md"}

#code
```vue
<template>
  <span class="text-faint">Faint</span>
  <span class="text-muted">Muted</span>
  <span class="text-default">Default</span>
  <span class="text-strong">Strong</span>
  <span class="text-contrast bg-neutral">Contrast</span>
</template>
```
::

Each utility class uses a CSS variable to set its color for light and dark modes:

::code-group
```css [Light]
:root {
  --ui-text-faint: var(--ui-color-neutral-400);
  --ui-text-muted: var(--ui-color-neutral-500);
  --ui-text-default: var(--ui-color-neutral-700);
  --ui-text-strong: var(--ui-color-neutral-900);
  --ui-text-contrast: white;
}
```

```css [Dark]
.dark {
  --ui-text-faint: var(--ui-color-neutral-500);
  --ui-text-muted: var(--ui-color-neutral-400);
  --ui-text-default: var(--ui-color-neutral-200);
  --ui-text-strong: white;
  --ui-text-contrast: var(--ui-color-neutral-900);
}
```
::

::tip
You can customize these CSS variables in your `main.css` file:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-text-default: var(--ui-color-neutral-900);
}

.dark {
  --ui-text-default: white;
}
```

Keep these rules outside `@layer theme`: the defaults sit in `@layer base`, which comes after it. To change all the text, background and border colors at once, [give `neutral` another palette](/docs/getting-started/theme/design-system#configure-colors) instead.
::

## Background

Nuxt UI provides Tailwind CSS utility classes for background colors, so you can use class names like `bg-default` or `bg-soft`:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[Default]{class="bg-default text-sm px-4 py-1.5 inline-block rounded-md"}
[Tint]{class="bg-tint text-sm px-4 py-1.5 inline-block rounded-md"}
[Soft]{class="bg-soft text-sm px-4 py-1.5 inline-block rounded-md"}
[Strong]{class="bg-strong text-sm px-4 py-1.5 inline-block rounded-md"}
[Neutral]{class="bg-neutral text-contrast text-sm px-4 py-1.5 inline-block rounded-md"}

#code
```vue
<template>
  <div class="bg-default">Default</div>
  <div class="bg-tint">Tint</div>
  <div class="bg-soft">Soft</div>
  <div class="bg-strong">Strong</div>
  <div class="bg-neutral text-contrast">Neutral</div>
</template>
```
::

Each utility class uses a CSS variable to set its color for light and dark modes:

::code-group
```css [Light]
:root {
  --ui-bg-default: white;
  --ui-bg-soft: var(--ui-color-neutral-100);
  --ui-bg-strong: var(--ui-color-neutral-200);
}
```

```css [Dark]
.dark {
  --ui-bg-default: var(--ui-color-neutral-900);
  --ui-bg-soft: var(--ui-color-neutral-800);
  --ui-bg-strong: var(--ui-color-neutral-700);
}
```
::

`bg-tint` is `bg-soft` at 50%, for hovered items and table heads. `bg-backdrop` is `bg-soft` at 75%, behind a Modal, a Slideover or a Drawer. Set `--ui-bg-tint` or `--ui-bg-backdrop` to replace them. Both are unset by default and the utilities hold the mix, so `var(--ui-bg-tint)` in your own CSS resolves to nothing, use `bg-tint` instead.

::tip
You can customize these CSS variables in your `main.css` file:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-bg-default: var(--ui-color-neutral-50);
}

.dark {
  --ui-bg-default: var(--ui-color-neutral-950);
}
```
::

### Overlay

The floating layers (DropdownMenu, ContextMenu, Popover, Tooltip, Select, Modal, Slideover, Drawer, Toast...) paint `bg-overlay`. It is `bg-default` until you set `--ui-bg-overlay`, so they match the page by default. You can use the class on your own floating elements too.

To lift them off the page, set `--ui-bg-overlay`. Inside a floating layer, the soft and strong backgrounds and the borders then move one step up, so highlighted items, separators and rings stay visible on the new surface. `bg-backdrop` moves to `bg-default` at 75%, so a Modal or a Slideover keeps its edge on it:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

.dark {
  --ui-bg-overlay: var(--ui-color-neutral-800);
}
```

To pick a step yourself, set `--ui-overlay-bg-soft`, `--ui-overlay-bg-strong`, `--ui-overlay-border-default` or `--ui-overlay-border-strong` next to `--ui-bg-overlay`. `--ui-bg-backdrop` still replaces the backdrop.

## Border

Nuxt UI provides Tailwind CSS utility classes for border colors, so you can use class names like `border-default` or `border-strong`:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[Default]{class="border-2 border-default text-sm px-4 py-1.5 inline-block rounded-md"}
[Strong]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-md"}
[Neutral]{class="border-2 border-neutral text-sm px-4 py-1.5 inline-block rounded-md"}

#code
```vue
<template>
  <div class="border border-default">Default</div>
  <div class="border border-strong">Strong</div>
  <div class="border border-neutral">Neutral</div>
</template>
```
::

Each utility class uses a CSS variable to set its color for light and dark modes:

::code-group
```css [Light]
:root {
  --ui-border-default: var(--ui-color-neutral-200);
  --ui-border-strong: var(--ui-color-neutral-300);
}
```

```css [Dark]
.dark {
  --ui-border-default: var(--ui-color-neutral-800);
  --ui-border-strong: var(--ui-color-neutral-700);
}
```
::

They also work with `ring-*`, `divide-*` and `ring-offset-*`, and `default` with `outline-*`, `fill-*` and `stroke-*`. `border-bg` and `ring-bg` use the page background, or the floating layer's inside one, like the ring that sets an avatar apart from the next one, and `bg-border` fills an element with the border color, like a separator.

::tip
You can customize these CSS variables in your `main.css` file:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-border-default: var(--ui-color-neutral-100);
}

.dark {
  --ui-border-default: var(--ui-color-neutral-900);
}
```
::

## Accent

The `color` prop of a component sets `--ui-accent` to that color, and the component's classes read `accent` utilities. The same classes give a soft badge in any color:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[Primary]{class="[--ui-accent:var(--ui-primary)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default text-sm px-4 py-1.5 inline-block rounded-md"}
[Success]{class="[--ui-accent:var(--ui-success)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default text-sm px-4 py-1.5 inline-block rounded-md"}
[Error]{class="[--ui-accent:var(--ui-error)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default text-sm px-4 py-1.5 inline-block rounded-md"}
[Neutral]{class="[--ui-accent:var(--ui-neutral)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default text-sm px-4 py-1.5 inline-block rounded-md"}

#code
```vue
<template>
  <span class="[--ui-accent:var(--ui-primary)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default">Primary</span>
  <span class="[--ui-accent:var(--ui-success)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default">Success</span>
  <span class="[--ui-accent:var(--ui-error)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default">Error</span>
  <span class="[--ui-accent:var(--ui-neutral)] bg-accent-soft text-accent-default ring ring-inset ring-accent-default">Neutral</span>
</template>
```
::

Each `accent` utility mirrors a neutral one, like `bg-accent-soft` for `bg-soft`. A color mixes itself at a fixed opacity, and `neutral` reads the neutral token:

| Utility | Colors | `neutral` |
| --- | --- | --- |
| `bg-accent`, `border-accent`… | The color | `--ui-neutral` |
| `bg-accent-hover` | The color at 75% | `--ui-neutral` at 90% |
| `bg-accent-tint` | The color at 5% | `bg-tint` |
| `bg-accent-soft` | The color at 10% | `bg-soft` |
| `bg-accent-strong` | The color at 15% | `bg-strong` at 75% |
| `text-accent`, `text-accent-strong` | `text-accent-default` | `text-strong` |
| `text-accent-default` | The color | `text-default` |
| `text-accent-muted` | `text-accent-default` at 75% | `text-muted` |
| `text-accent-faint` | `text-accent-default` at 50% | `text-faint` |
| `text-accent-contrast` | `text-contrast` | `text-contrast` |
| `border-accent-default` | The color at 25% | `border-default` |
| `border-accent-strong` | The color at 50% | `border-strong` |
| `outline-accent-focus` | The color at 25% | `--ui-neutral` at 25% |

`border-accent-*` also works with `ring-*` and `divide-*`. A role only exists on the property it's meant for, so `bg-accent-soft` works but `text-accent-soft` doesn't. `--ui-accent` itself works with any color utility, like `fill-accent` or `shadow-accent/30`.

### Override a role

Each color has a CSS variable per role, unset by default, like `--ui-warning-bg-soft` or `--ui-warning-text-contrast`. Set one to change that role for one color in every component, like dark text on a `warning` solid:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-warning-text-contrast: var(--ui-color-neutral-900);
}
```

`--ui-neutral-<role>` works the same for neutral.

### Colored text

The text of a color is `--ui-<color>-text-default`, which is the color itself by default. It colors `text-primary`, `text-accent` and the labels of the `soft`, `subtle`, `outline`, `ghost` and `link` variants. Set it to change the text of a color without touching its solid.

At shade `500`, `primary`, `success` and `warning` text is under 3:1 on white. To darken the text in light mode only:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-primary-text-default: var(--ui-color-primary-700);
}

.dark {
  --ui-primary-text-default: initial;
}
```

These shades reach 4.5:1 for the default colors, on the page and on soft fills:

| Color | Shade |
| --- | --- |
| `primary`{color="primary"} | `700` |
| `secondary`{color="secondary"} | `600` |
| `success`{color="success"} | `700` |
| `info`{color="info"} | `700` |
| `warning`{color="warning"} | `800` |
| `error`{color="error"} | `700` |

::note
The `link` Button and the Avatar fallback use `--ui-<color>-text-muted`. Set it to the same shade for those to reach 4.5:1 too.
::

### Outside a component

Set `--ui-accent` through a class to use the `accent` utilities in your own markup, like the preview above. The same class recolors a component outside its `color` prop:

```vue
<template>
  <UButton class="[--ui-accent:var(--color-indigo-500)]" label="Button" />
</template>
```

::warning
The roles follow that exact class. With `!`, a variant like `hover:` or an inline `style`, only `--ui-accent` changes, so a neutral component keeps its neutral fills, text and borders.
::

::note
Some parts set their own `--ui-accent`, so a `class` on the component doesn't reach them: colored items in DropdownMenu and ContextMenu, ProgressGroup segments, NavigationMenu links, the Table loading bar, the Timeline indicator, the active indicator of ContentToc and the Chip dot. Change them through `ui` instead. Nested components also keep their own color, like the buttons of an InputNumber.
::

## Focus

Interactive elements show a `focus-visible` outline at 25% of their color, through `outline-accent-focus`. Components without a `color` prop use `outline-focus`, `primary` at 25%. The `--ui-focus-width` CSS variable sets the width of the outline:

```css
:root {
  --ui-focus-width: 3px;
}
```

::tip
You can customize it in your `main.css` file, with `--ui-outline-focus` for components without a `color` prop and `--ui-<color>-outline-focus` for one color:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-focus-width: 2px;
  --ui-outline-focus: color-mix(in oklab, var(--ui-neutral) 25%, transparent);
  --ui-primary-outline-focus: color-mix(in oklab, var(--ui-primary) 50%, transparent);
}
```
::

## Disabled

```css

  --ui-disabled-opacity: 75%;
}
```

::tip
You can customize this value in your `main.css` file:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-disabled-opacity: 50%;
}
```

## Control

Buttons, badges, fields and the links of a NavigationMenu read their spacing from CSS variables, set per `size`, or per `orientation` on a NavigationMenu:

| Variable | Used for | `md` on a Button |
| --- | --- | --- |
| `--ui-control-px` | Horizontal padding | `--spacing(2.5)` |
| `--ui-control-py` | Vertical padding | `--spacing(1.5)` |
| `--ui-control-gap` | Gap between an icon and the label | `--spacing(1.5)` |
| `--ui-control-icon` | Size of the leading and trailing icons | `--spacing(5)` |
| `--ui-control-text-step` | Added to the text size of a field, `0px` by default | - |

The variables sit on the element `class` lands on: `base` on a Button or a Select, `root` on an Input or a Textarea. Restyle a size through them rather than a padding like `px-4`, so icon-only buttons stay square and fields keep their icon spacing:

::framework-only
#nuxt
:::div
```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    button: {
      variants: {
        size: {
          md: {
            base: '[--ui-control-px:--spacing(4)] [--ui-control-py:--spacing(2)]'
          }
        }
      }
    }
  }
})
```
:::

#vue
:::div
```ts [src/main.ts]
app.use(ui, {
  ui: {
    button: {
      variants: {
        size: {
          md: {
            base: '[--ui-control-px:--spacing(4)] [--ui-control-py:--spacing(2)]'
          }
        }
      }
    }
  }
})
```
:::
::

Or set them through `class` to change one instance:

```vue
<template>
  <UInput icon="i-lucide-search" class="[--ui-control-icon:--spacing(4)]" />
</template>
```

The `square` prop of Button, Badge and NavigationMenu sets the horizontal padding to the vertical one, so it follows a size you restyle. A size you add to a component needs these variables too, for `square` and icons to work with it.

::tip
iOS Safari zooms on a focused field whose text is under 16px. To avoid it, make fields larger on small screens with `--ui-control-text-step`. With this value, `md` and `lg` fields reach 16px:

```css [app/assets/css/main.css]
@media (width < 48rem) {
  :root {
    --ui-control-text-step: 0.125rem;
  }
}
```
::

::note
Slider, Progress, ProgressGroup and Separator read `--ui-control-thickness` for the size of their track or line. Calendar, Timeline and Stepper read `--ui-control-size` for their cells and indicators.
::

## Radius

Nuxt UI overrides Tailwind CSS's default `rounded-*` utilities with a unified border radius system, so you can use regular [border radius utilities](https://tailwindcss.com/docs/border-radius) like `rounded-xs` or `rounded-2xl`:

::code-preview{class="[&>div>p]:flex [&>div>p]:flex-wrap [&>div>p]:gap-2"}
[xs]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-xs"}
[sm]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-sm"}
[md]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-md"}
[lg]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-lg"}
[xl]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-xl"}
[2xl]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-2xl"}
[3xl]{class="border-2 border-strong text-sm px-4 py-1.5 inline-block rounded-3xl"}

#code
```vue
<template>
  <div class="rounded-xs">xs</div>
  <div class="rounded-sm">sm</div>
  <div class="rounded-md">md</div>
  <div class="rounded-lg">lg</div>
  <div class="rounded-xl">xl</div>
  <div class="rounded-2xl">2xl</div>
  <div class="rounded-3xl">3xl</div>
</template>
```
::

These utility classes are calculated from a global `--ui-radius` CSS variable:

```css
:root {
  --ui-radius: 0.25rem;
}
```

Each utility multiplies this base value, inline so a `--ui-radius` set on a part of the page applies there too:

```css
@theme inline {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::tip
You can customize the base radius value in your `main.css` file:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-radius: 0.5rem;
}
```
::

::warning
Changing `--ui-radius` also affects the `rounded-xs` to `rounded-3xl` classes on your own markup and third-party components, not only Nuxt UI components.
::

## Font

Nuxt UI provides a `--font-heading` theme variable that sets the font of the `h1` to `h6` elements, the [Prose](/docs/typography) headings and the titles of components like [Card](/docs/components/card), [Modal](/docs/components/modal) or [PageHero](/docs/components/page-hero). The `--ui-font-weight-heading` CSS variable sets the weight of the Prose headings and of the component titles, and `--ui-font-weight-body` the weight of the body text. Plain `h1` to `h6` elements only take the font.

All three are unset by default: headings keep the body font, the body text stays at `400`, and each title keeps its own weight, like bold on page titles. The smaller titles of Alert, Toast, Banner, Timeline or Stepper are labels and keep the body font.

::tip
Set the font in `@theme`, like the other [fonts](/docs/getting-started/theme/design-system#fonts), and the weights in `:root`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-heading: 'Outfit', var(--font-sans);
}

:root {
  --ui-font-weight-body: 450;
  --ui-font-weight-heading: 500;
}
```
::

`--font-heading` is a CSS variable too, so you can change it on a part of the page:

```vue
<template>
  <UCard class="[--font-heading:var(--font-serif)]" title="Card" />
</template>
```

## Container

Nuxt UI provides a `--ui-container` CSS variable that controls the maximum width of the [Container](/docs/components/container) component.

```css
:root {
  --ui-container: 80rem;
}
```

::tip
You can customize this value in your `main.css` file to adjust container widths throughout your application:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```
::

## Gutter

Nuxt UI provides a `--ui-gutter` CSS variable that sets the side padding of the [Container](/docs/components/container), so of the page, and the padding of the [Card](/docs/components/card), [Modal](/docs/components/modal) and [Slideover](/docs/components/slideover) parts, the [Header](/docs/components/header) menu, the [PageCard](/docs/components/page-card) and the dashboard panels.

```css
:root {
  --ui-gutter: --spacing(4);

  @variant sm {
    --ui-gutter: --spacing(6);
  }
}
```

::tip
You can customize this value in your `main.css` file, with one value or one per breakpoint:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-gutter: --spacing(3);

  @variant sm {
    --ui-gutter: --spacing(4);
  }
}
```
::

## Header

Nuxt UI provides a `--ui-header-height` CSS variable that controls the height of the [Header](/docs/components/header) component. [Main](/docs/components/main) and [Error](/docs/components/error) fill the viewport below it, [PageAside](/docs/components/page-aside) sticks under it, and the headers of Modal, Slideover and Sidebar use it as their minimum height.

```css
:root {
  --ui-header-height: 4rem;
}
```

::tip
You can customize this value in your `main.css` file:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-header-height: --spacing(24);
}
```
::

## Body

Nuxt UI applies default styles on the `<body>`{lang="html"} element of your app for consistent theming across light and dark modes:

```css
@layer base {
  body {
    -webkit-font-smoothing: antialiased;
    -moz-osx-font-smoothing: grayscale;
    color: var(--ui-text-default);
    background-color: var(--ui-bg-default);
    color-scheme: light;
  }

  body:where(.dark, .dark *) {
    color-scheme: dark;
  }
}
```

It also points the body weight and the heading font at their [variables](#font), at zero specificity so your own `body` or `h1` rules win:

```css
@layer base {
  :where(body) {
    font-weight: var(--ui-font-weight-body);
  }

  :where(h1, h2, h3, h4, h5, h6) {
    font-family: var(--font-heading, inherit);
  }
}
```
