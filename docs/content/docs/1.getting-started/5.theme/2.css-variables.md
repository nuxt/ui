Each token is a CSS variable, most of them behind a Tailwind utility. `neutral-400` below stands for `var(--ui-color-neutral-400)`, so the surfaces follow the palette of `neutral`.

| Token | Light | Dark | Used for |
| --- | --- | --- | --- |
| `--ui-primary`, `--ui-secondary`, `--ui-success`, `--ui-info`, `--ui-warning`, `--ui-error` | Shade `500` | Shade `400` | `text-primary`, `bg-error`… |
| `--ui-neutral` | Shade `900` | Shade `50` | `text-neutral`, `bg-neutral`… |
| `--ui-text-dimmed` | `neutral-400` | `neutral-500` | `text-dimmed`, placeholders |
| `--ui-text-muted` | `neutral-500` | `neutral-400` | `text-muted`, descriptions |
| `--ui-text-toned` | `neutral-600` | `neutral-300` | `text-toned` |
| `--ui-text` | `neutral-700` | `neutral-200` | `text-default`, body text |
| `--ui-text-highlighted` | `neutral-900` | `white` | `text-highlighted`, titles |
| `--ui-text-inverted` | `white` | `neutral-900` | `text-inverted`, text on an inverted background |
| `--ui-bg` | `white` | `neutral-900` | `bg-default`, the page |
| `--ui-bg-muted` | `neutral-50` | `neutral-800` | `bg-muted` |
| `--ui-bg-elevated` | `neutral-100` | `neutral-800` | `bg-elevated`, raised surfaces |
| `--ui-bg-accented` | `neutral-200` | `neutral-700` | `bg-accented` |
| `--ui-bg-inverted` | `neutral-900` | `white` | `bg-inverted`, an inverted surface |
| `--ui-border` | `neutral-200` | `neutral-800` | `border-default` |
| `--ui-border-muted` | `neutral-200` | `neutral-700` | `border-muted` |
| `--ui-border-accented` | `neutral-300` | `neutral-700` | `border-accented` |
| `--ui-border-inverted` | `neutral-900` | `white` | `border-inverted` |
| `--ui-accent-foreground` | `--ui-text-inverted` | Same | `text-accent-foreground`, text on a solid accent background |
| `--ui-accent-hover` | `--ui-accent` at 75% | Same | `bg-accent-hover`, the hover of a solid background |
| `--ui-accent-soft` | `--ui-accent` at 10% | Same | `bg-accent-soft`, a tinted background |
| `--ui-accent-soft-foreground` | `--ui-accent` | Same | `text-accent-soft-foreground`, text on a tinted background |
| `--ui-accent-border` | `--ui-accent` at 50% | Same | `ring-accent-border`, a colored border |
| `--ui-accent-border-soft` | `--ui-accent` at 25% | Same | `ring-accent-border-soft`, a lighter colored border |
| `--ui-accent-focus` | `--ui-accent` at 25% | Same | `outline-accent-focus`, the focus outline |
| `--ui-radius` | `0.25rem` | Same | The base of the [`rounded-*` scale](#radius) |
| `--ui-container` | `80rem` | Same | The max width of [Container](#container) |
| `--ui-header-height` | `4rem` | Same | The height of [Header](#header) |

The border tokens also work with `ring-*` and `divide-*`, and every accent role works with any color utility, like `text-accent` or `border-accent-border`.

Override a token in your `main.css`. A value on `:root` applies in both modes, and one on `.dark` takes over in dark mode:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-bg: var(--ui-color-neutral-50);
}

.dark {
  --ui-bg: var(--ui-color-neutral-950);
}
```

To change all the surfaces at once, [give `neutral` another palette](/docs/getting-started/theme/design-system#configure-colors) instead.

## Accent

The `color` prop puts a class like `[--ui-accent:var(--ui-primary)]` on the component. That class also points each accent role at a variable of the color, `--ui-primary-soft`, `--ui-primary-foreground` and so on. They are unset by default, so the roles take the values in the table. Set one to change a role of one color, and every component follows. For example, dark text on a yellow `warning`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-warning-foreground: var(--ui-color-neutral-900);
}
```

`neutral` points its roles at the surface tokens instead (`bg-elevated`, `text-default`, `ring-accented`…), which is how a neutral component keeps its look. `--ui-neutral-soft` and the other `--ui-neutral-<role>` variables override them the same way. `color="neutral"` uses the same classes as every other color, except in Callout, inline Code, Calendar, ChatMessage and Separator. Components also read a few roles of their own that aren't listed here, which can change between versions.

The accent utilities work in your own markup too. Set `--ui-accent` through a class to pick the color:

```vue
<template>
  <div class="[--ui-accent:var(--ui-error)] bg-accent-soft text-accent-soft-foreground">
    Something went wrong
  </div>
</template>
```

The same class recolors a component outside its `color` prop, like `<UButton class="[--ui-accent:var(--color-indigo-500)]" />`. A few parts set their own and take it through `ui` instead: items with their own color in DropdownMenu and ContextMenu, the segments of a ProgressGroup, the links of a NavigationMenu, the loading bar of a Table (`loading-color`), the indicator of a Timeline and the dot of a Chip. Components nested inside keep their own color too, like the buttons of an InputNumber.

The roles key on that exact class. A scope written with `!` (`![--ui-accent:…]`), a variant prefix (`hover:`, `md:`) or an inline `style` changes `--ui-accent` but keeps the roles of the component's own color, so a neutral soft, outline, subtle, ghost or link component, whose roles point at the surface tokens, ignores it apart from its focus styles. A custom color like `tertiary` has no role variables: set the role next to it instead, like `[--ui-accent-foreground:var(--ui-color-neutral-900)]`.

## Radius

`--ui-radius` is the base of Tailwind's `rounded-*` utilities, which Nuxt UI redefines in `@theme`:

```css
@theme default inline {
  --radius-xs: calc(var(--ui-radius) * 0.5);
  --radius-sm: var(--ui-radius);
  --radius-md: calc(var(--ui-radius) * 1.5);
  --radius-lg: calc(var(--ui-radius) * 2);
  --radius-xl: calc(var(--ui-radius) * 3);
  --radius-2xl: calc(var(--ui-radius) * 4);
  --radius-3xl: calc(var(--ui-radius) * 6);
}
```

::warning
Changing `--ui-radius` also affects the `rounded-xs` to `rounded-3xl` classes on your own markup and third-party components, not only Nuxt UI components.
::

## Container

The [Container](/docs/components/container) component takes its max width from `--ui-container`. Point it at another size to change every container at once:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --container-8xl: 90rem;
}

:root {
  --ui-container: var(--container-8xl);
}
```

## Header

The [Header](/docs/components/header) component takes its height from `--ui-header-height`. [Main](/docs/components/main) and [Error](/docs/components/error) fill the viewport below it, and [PageAside](/docs/components/page-aside) sticks under it:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  --ui-header-height: --spacing(24);
}
```
