Nuxt UI provides beautifully styled **Prose components** for your markdown content. Whether you render markdown with a library or use prose components directly, Nuxt UI applies its design system so your content automatically adapts to your application's theme.

Markdown elements are automatically mapped to prose components: `# Heading` becomes `<ProseH1>`, `**bold**` becomes `<ProseStrong>`, `` `code` `` becomes `<ProseCode>`, and so on.

::framework-only
#nuxt
:::note
Prose components are automatically enabled when using [`@nuxtjs/mdc`](https://github.com/nuxt-modules/mdc), [`@nuxt/content`](/docs/getting-started/integrations/content) or [`@comark/nuxt`](https://comark.dev/rendering/nuxt).<br><br>Otherwise, enable the [`prose`](/docs/getting-started/installation/nuxt#prose) option in your `nuxt.config.ts`:

```ts [nuxt.config.ts] {4}
export default defineNuxtConfig({
  modules: ['@nuxt/ui'],
  ui: {
    prose: true
  }
})
```
:::

#vue
:::note
To use prose components with Vue, you need to enable the `prose` option in your `vite.config.ts`:

```ts [vite.config.ts] {9}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```
:::
::

## Usage

::framework-only
#nuxt
:::div
There are multiple ways to render styled content:

1. **Markdown Rendering** - Use ContentRenderer, MDC, Comark or ComarkRenderer to render markdown with automatic prose styling
2. **Direct Vue Usage** - Import and use prose components directly in your Vue templates
:::

#vue
:::div
There are multiple ways to render styled content:

1. **Markdown Rendering** - Use Comark or ComarkRenderer to render markdown with automatic prose styling
2. **Direct Vue Usage** - Import and use prose components directly in your Vue templates
:::

::

### With ContentRenderer :badge{label="Nuxt only" class="align-text-top"}

When using Nuxt Content, the simplest way to render styled markdown is with the [`<ContentRenderer>`](https://content.nuxt.com/components/content-renderer) component:

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

### With MDC component :badge{label="Nuxt only" class="align-text-top"}

When using Nuxt Content or Nuxt MDC, use the [`<MDC>`](https://github.com/nuxt-modules/mdc) component to render markdown strings:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-modules/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

::note
Use this when rendering markdown from external sources like APIs, databases or user-generated content.
::

### With Comark component

When using [Comark](https://comark.dev), use the `<Comark>` component for streaming markdown such as AI chat responses. It incrementally renders tokens as they arrive, avoiding the flicker and re-parsing that traditional markdown renderers cause.

::framework-only
#nuxt
```vue
<script setup lang="ts">
import highlight from '@comark/nuxt/plugins/highlight'

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Comark :markdown="markdown" :plugins="[highlight()]" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Comark } from '@comark/vue'
import highlight from '@comark/vue/plugins/highlight'

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Comark :markdown="markdown" :plugins="[highlight()]" />
</template>
```
::

::note
Use this when rendering streaming content like AI chat responses. The `highlight` plugin adds syntax highlighting to code blocks.
::

::tip{to="/docs/components/chat"}
See the **Chat** component for a full example of using Comark to render AI chat messages.
::

### With ComarkRenderer

When using [Comark](https://comark.dev), use the [`<ComarkRenderer>`](https://comark.dev/rendering/vue#code-comarkrenderer) component to render a pre-parsed `ComarkTree` without shipping any parser or plugin code to the browser. This is useful when parsing happens on the server, in a build step, or via an API.

::framework-only
#nuxt
```vue
<script setup lang="ts">
const { data: tree } = await useFetch('/api/content')
</script>

<template>
  <ComarkRenderer v-if="tree" :tree="tree" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { ComarkRenderer } from '@comark/vue'

const tree = ref()

onMounted(async () => {
  tree.value = await fetch('/api/content').then(r => r.json())
})
</script>

<template>
  <ComarkRenderer v-if="tree" :tree="tree" />
</template>
```
::

### With Prose components

Use prose components directly in Vue templates for maximum control:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## Theme

Override any prose component styling in your app configuration:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
