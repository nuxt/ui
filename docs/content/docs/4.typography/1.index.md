Nuxt UI provides custom styling for the **Prose components** from [@nuxtjs/mdc](https://github.com/nuxt-modules/mdc), which transform your markdown into beautifully styled, theme-aware content.

The MDC module handles the markdown transformation and component structure, while Nuxt UI overrides them with its design system styling. These components integrate seamlessly with both MDC and [@nuxt/content](https://content.nuxt.com) to provide multiple ways to create rich, interactive documentation.

::note{to="/docs/getting-started/integrations/content"}
For Nuxt Content installation and setup, see the **Content integration** guide.
::

## How Typography Works in Nuxt UI

The typography system, powered by MDC's prose components and styled by Nuxt UI, provides three complementary approaches:

1. **Automatic Prose Rendering** - Markdown automatically converts to styled prose components
2. **MDC Syntax** - Use Vue components directly in markdown files with `::component` notation
3. **Direct Vue Usage** - Import and use prose components in your Vue templates

## Usage

### Method 1: Using ContentRenderer

The simplest way - your markdown is automatically styled when using [`<ContentRenderer>`](https://content.nuxt.com/components/content-renderer) component:

```vue [pages/[...slug].vue]
<template>
  <main>
    <ContentRenderer :value="page" />
  </main>
</template>

<script setup>
const route = useRoute()
const { data: page } = await useAsyncData(
  route.path,
  () => queryContent(route.path).findOne()
)
</script>
```

Your markdown automatically transforms:
- `# Heading` → `<ProseH1>` with anchor links
- `**bold**` → `<ProseStrong>` with theme styling
- `` `code` `` → `<ProseCode>` with syntax highlighting
- And all other markdown elements...

### Method 2: Using MDC Component

For more control over markdown rendering, use the [`<MDC>`](https://github.com/nuxt-modules/mdc) component:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-modules/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

This is useful when:
- Rendering markdown from external sources (APIs, databases)
- Passing custom data to components
- Building dynamic content systems
- Processing user-generated markdown

### Method 3: Direct Prose Components

Use prose components directly in Vue templates for maximum control:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
</script>
```

## Customization

Override any prose component styling in your app configuration:

```ts [app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      // Headings
      h1: {
        base: 'text-5xl font-bold tracking-tight'
      },
      h2: {
        base: 'text-3xl font-semibold mt-10 mb-4'
      },
      // Paragraphs
      p: {
        base: 'text-base leading-7 [&:not(:first-child)]:mt-6'
      },
      // Code
      code: {
        base: 'px-1.5 py-0.5 rounded-md',
        variants: {
          color: {
            primary: 'bg-primary/10 text-primary'
          }
        }
      },
      // Lists
      ul: {
        base: 'space-y-1 list-disc list-inside'
      },
      // Tables
      table: {
        base: 'w-full text-sm'
      }
    }
  }
})
```
