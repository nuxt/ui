::framework-only
#nuxt
Nuxt UI brings beautiful, consistent styling to your markdown through **Prose components**. Whether you use [@nuxtjs/mdc](https://github.com/nuxt-modules/mdc) to transform markdown into semantic Vue components, or [@comark/nuxt](https://comark.dev/rendering/nuxt) for streaming markdown rendering, Nuxt UI applies its design system so your content automatically adapts to your application's theme.

#vue
Nuxt UI brings beautiful, consistent styling to your markdown through **Prose components**. Use [@comark/vue](https://comark.dev/rendering/vue) for streaming markdown rendering, or import prose components directly. Nuxt UI applies its design system so your content automatically adapts to your application's theme.
::

::framework-only
#nuxt
:::note{to="/docs/getting-started/integrations/content"}
For Nuxt Content installation and setup, check the **Content integration** guide.
:::

#vue
:::note
To use prose components with Vue, you need to enable the `prose` option in your `vite.config.ts`:

```ts [vite.config.ts] {4}
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import ui from '@nuxt/ui/vite'

export default defineConfig({
  plugins: [
    vue(),
    ui({
      prose: true
    })
  ]
})
```
:::
::

## Usage

::framework-only
#nuxt
:::div
The typography system, styled by Nuxt UI, provides multiple ways to render styled content:

1. **Markdown Rendering** - Use ContentRenderer, MDC or Comark component to render markdown with automatic prose styling
2. **Direct Vue Usage** - Import and use prose components directly in your Vue templates
:::

#vue
:::div
The typography system, styled by Nuxt UI, provides multiple ways to render styled content:

1. **Markdown Rendering** - Use the Comark component to render markdown with automatic prose styling
2. **Direct Vue Usage** - Import and use prose components directly in your Vue templates
:::

::

### With ContentRenderer :badge{label="Nuxt only"}

::framework-only
#nuxt
The simplest way - your markdown is automatically styled when using [`<ContentRenderer>`](https://content.nuxt.com/components/content-renderer) component:

```vue [pages/\[...slug\\].vue]
<script setup lang="ts">
const route = useRoute()

const { data: page } = await useAsyncData(route.path, () => queryCollection('docs').path(route.path).first())
</script>

<template>
  <ContentRenderer :value="page" />
</template>
```

:::note
When you write markdown, Nuxt MDC automatically maps each element to a styled prose component:
- `# Heading` → `<ProseH1>` (with accessible anchor links)
- `**bold**` → `<ProseStrong>` (styled according to your theme)
- `` `code` `` → `<ProseCode>` (with syntax highlighting)
- ...and all other markdown syntax is rendered as their corresponding prose components, ensuring consistent design and theming.
:::
::

### With MDC component :badge{label="Nuxt only"}

::framework-only
#nuxt
For more control over markdown rendering, use the [`<MDC>`](https://github.com/nuxt-modules/mdc) component:

```vue
<script setup lang="ts">
const value = `# Hello World

Learn more about the **MDC** component in the [documentation](https://github.com/nuxt-modules/mdc).
`
</script>

<template>
  <MDC :value="value" />
</template>
```

:::note
Use this approach when you need to:
- Render markdown content from external sources such as APIs or databases
- Inject dynamic or custom data into your markdown
- Build flexible, dynamic content systems
- Safely process and display user-generated markdown
:::
::

### With Comark component

For streaming markdown such as AI chat responses, use the [`<Comark>`](https://comark.dev) component. It incrementally renders tokens as they arrive, avoiding the flicker and re-parsing that traditional markdown renderers cause. It also automatically enables Nuxt UI's prose components so your content is styled to match your theme.

::framework-only
#nuxt
```vue
<script setup lang="ts">
import highlight from '@comark/nuxt/plugins/highlight'

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Comark :markdown="markdown" :streaming="true" :plugins="[highlight()]" />
</template>
```

#vue
```vue
<script setup lang="ts">
import { Comark } from '@comark/vue'
import highlight from '@comark/vue/plugins/highlight'

const markdown = ref('# Hello World\n\nThis is **streaming** markdown.')
</script>

<template>
  <Comark :markdown="markdown" :streaming="true" :plugins="[highlight()]" />
</template>
```
::

::note
Use this approach when you need to:
- Render streaming AI responses with incremental rendering
- Display dynamic markdown that updates in real-time
- Render markdown with syntax highlighting via the `highlight` plugin
::

::tip{to="/docs/components/chat"}
See the **Chat** component for a full example of using Comark to render AI chat messages.
::

### With Prose components

Use prose components directly in Vue templates for maximum control:

```vue
<template>
  <ProseTable>
    <ProseThead>
      <ProseTr>
        <ProseTh>Prop</ProseTh>
        <ProseTh>Default</ProseTh>
      </ProseTr>
    </ProseThead>
    <ProseTbody>
      <ProseTr>
        <ProseTd>
          <ProseCode>color</ProseCode>
        </ProseTd>
        <ProseTd>
          <ProseCode>neutral</ProseCode>
        </ProseTd>
      </ProseTr>
    </ProseTbody>
  </ProseTable>
</template>
```

## Theme

Override any prose component styling in your app configuration:

```ts [app/app.config.ts]
export default defineAppConfig({
  ui: {
    prose: {
      h1: {
        slots: {
          base: 'scroll-m-20 text-4xl font-extrabold tracking-tight lg:text-5xl'
        }
      },
      p: {
        base: 'leading-7 [&:not(:first-child)]:mt-6'
      }
    }
  }
})
```
