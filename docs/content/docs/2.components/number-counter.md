## Usage

Use the `value` prop to set the value of the NumberCounter.

::component-code
---
props:
  value: 1024
---
::

### Trend

Use the `trend` prop to set the trend of the NumberCounter.

::component-code
---
props:
  value: 1024
  trend: 2
---
::

### Prefix

Use the `prefix` prop to set the prefix of the NumberCounter.

::component-code
---
props:
  value: 1024
  prefix: '$'
---
::

### Suffix

Use the `suffix` prop to set the suffix of the NumberCounter.

::component-code
---
props:
  value: 1024
  suffix: '$'
---
::

### Animated

Use the `animated` prop to set the animated of the NumberCounter.

::component-code
---
props:
  value: 1024
  animated: false
---
::
