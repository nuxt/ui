# Contributing to Nuxt UI

Thanks for your interest in contributing to Nuxt UI! ❤️

The contribution guide lives in the documentation: https://ui.nuxt.com/docs/getting-started/contribution

It covers the project structure, the CLI, local development, linting, testing, commit conventions and how to submit a pull request.

- For questions and help, use [GitHub Discussions](https://github.com/nuxt/ui/discussions/categories/q-a).
- To report a bug or request a feature, check the existing [issues](https://github.com/nuxt/ui/issues) first.
- If you use an AI coding agent, [`AGENTS.md`](./AGENTS.md) is picked up automatically.
